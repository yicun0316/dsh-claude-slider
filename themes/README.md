# DSH Claude Slider 动效库

16 款可独立导入的 v1 动效包，包括移植自 v2.13 的 11 款经典动效和 5 款自定义示例。作者见各动效包的 `author` 字段。

**3 秒导入。** 保存下表中的任意 `.dcs-effect.json`，在插件设置中打开「动效」→「自定义」→「导入文件」，选中刚保存的文件。也可以在 [自由定制动效工坊](../studio/index.html) 点击「粘贴 / 导入 JSON」，选择文件或粘贴完整 JSON，再点「校验并载入」实时试玩。

`theme` 跟随主题色和莫奈取色。 `tinted` 保留动效自身的主色调，并混入主题色高光。
