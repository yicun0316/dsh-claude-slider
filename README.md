# DSH Claude 风格超炫酷推理强度滑块插件 (`dsh-claude-slider`)

为 **DeepSeek Harness (DSH Desktop & Web)** 专属打造的 **Claude 风格推理强度（Reasoning Effort / Thinking）滑块插件**。  
深度还原 Claude 官方输入框悬浮交互，并基于严谨的物理与视觉设计哲学重构了 **全系四字纯净命名动效库**（火箭尾焰、离子飞箭、超载折跃、星流碎钻、幽夜暗潮等 23 种跨维度动效）、**三段式 MAX 状态机**、**粒子预算分档**、**1.5s 静止收敛降噪**、**客制动效参数设计**与 **JSON 配置导入导出分享**，支持随时恢复 DSH 原生设计的主开关、出厂配置一键重置、档位吸附机械微触感音效、全新纯净满幅 **DeepSeek 鲸鱼娘**专属头像、动效流速与发光亮度平滑微调、官方原生矢量图标、本地 PNG / JPG 图片上传与全色谱联动调色盘！

## ✨ 核心特色与 v2.9.0 全新升级

### 1. 全系四字纯净命名 & 紧凑空间布局
- **彻底删除冗长介绍**：剔除占地繁复的文字段落与标签，全部动效精炼为统一的**四字中文章法命名**（如“火箭尾焰”、“离子飞箭”、“星流碎钻”、“幽夜暗潮”等）；
- **极简 3 列紧凑瓷砖网格**：动效选择器升级为专业调色板式的三列轻质按钮网格，节省超过 80% 垂直空间，直观利落、一目了然！

### 2. 经典重塑改名
- 原“喷射流光”升级改名为 **星流碎钻**：满轨柔和渐变与高密碎钻星火喷射；
- 原“暗流涌动”升级改名为 **幽夜暗潮**：深邃宝石底色与弥散外发光光晕，涌动发光流体烟岚与星云。

### 3. 🚀 全新尾部火箭流光粒子家族（重磅加入）
针对航天火箭与星际推进器的真实高能流体动力学量身打造：
- **🚀 火箭尾焰 (`rocket_thrust`)**：  
  手柄作为高能推进喷口，向左后方喷射高温火羽与马赫激波锥（Mach Diamonds）；燃烧火星颗粒以极高速度向后飞溅拉长拖尾，MAX 档激波剧烈震荡喷涌！
- **🚀 离子飞箭 (`ion_stream`)**：  
  深空航天高压准直蓝色等离子尾喷束，带电微粒子如利箭般向后极速穿梭，呈现科幻感十足的高速推力质感。
- **🚀 超载折跃 (`warp_boost`)**：  
  星舰超光速时空激波光锥尾流，多普勒蓝移与红移尾流向后拉伸，伴随时空曲率折跃激波。

### 4. 🛠️ 支持客制动效 (自定义动效设计) & 📤 导入导出 JSON 分享码
- **客制动效 (`custom_flow`)**：  
  当选中“客制动效”时，可自由定制属于您自己的动效组合：
  - **粒子形态（10 种）**：🔥 炽焰 / 💎 晶体 / ⭐ 星芒 / ⚪ 圆点 / 🌫️ 光雾 / 🌸 花瓣 / 🌙 弧光 / 🫧 气泡 / 💡 霓虹 / 🔷 碎片；
  - **运动动力学（8 种）**：🚀 推进 / ➡️ 星流 / 💥 对撞 / 🌊 波涌 / 🌀 涡旋 / ⚡ 跃迁 / ✨ 爆发 / 🪐 环绕；
- **配置分享（“抄作业”神器）**：  
  抽屉与设置页顶部新增 **📤 导出配置** 与 **📥 导入配置** 按钮。一键将当前图标、配色、动效模式与自定义参数复制为 JSON 分享码，他人粘贴即可一键复刻整套方案！

### 5. 彻底删除算力预算胶囊
- 响应用户建议，彻底移除滑块上方的算力预算悬浮提示胶囊（Thinking Budget Tooltip），告别多余气泡干扰，让滑块交互更加纯粹、聚焦、清爽。

### 6. 三段式 MAX 状态机：关键是“事件”而不是“更亮”
告别以往单纯在 MAX 档位把参数乘系数（overdrive）的刺眼闪烁，引入专业级的三段式生命周期状态机：
- **① 爆发 Burst（0.65s，边沿触发 + 冷却保护）**：  
  当手柄跨越进入 MAX 档瞬间触发：径向冲击波环全轨扩散、全轨柔和高光冲洗、手柄微幅轻弹（1.06x）与色温瞬时拉高。绝非每帧持续闪烁，告别光敏眩晕！
- **② 巡航 Cruise（持续运行）**：  
  粒子数扩容至 120 满载、流速提升 1.5x、开启反向对撞流光、暗色主题开启 `lighter` 加色混合、每隔 3.5s 涌动一次微脉冲呼吸，赋予动效充沛生命力。
- **③ 余韵 Afterglow（0.4s，降档回落）**：  
  当用户从 MAX 档向下拉回 High / Low 时，主发光迅速回落，但保留一段淡出的星尘流光尾迹，带来极其舒适的阻尼余温。

### 7. 随时恢复原样的主开关（【高级的推理强度选择】）
- **完全复刻原生配置规范**：在设置中心与滑块抽屉内置主开关，开启后使用滑块式调节并可选震撼特效；**关闭则注销插槽接管，自动无缝恢复为 DSH 默认原生设计（原生触发器与多级菜单）**！
- **无感平滑切换**：开关变动即时响应，无需重启或重新编译，随心在经典原生与 Claude 炫酷滑块之间切换。

## 🚀 快速体验与安装

### 方式一：直接在浏览器中打开独立演示（无需启动 DSH）
- 双击打开 `demo/index.html`，即可直接在浏览器体验 23 种纯净四字动效切换、火箭尾焰喷射、客制动效设计、配置导出导入与流速/亮度微调！

### 方式二：一键安装至本地 DSH 客户端
已内置跨平台快速安装脚本：
- **Windows**：双击运行项目根目录下的 `install.bat` 即可自动链接挂载至 DSH Desktop 与 DSH Web。
- 安装后在 DeepSeek Harness 客户端窗口中按下 **`Ctrl + R`** 刷新即可生效！

### 方式三：装到别人的机器上（分发用）
不需要 clone 仓库，两条命令任选其一：

```bash
# 从 npm 安装（发布到 npm 后可用）
dsh plugin --profile desktop add dsh-claude-slider

# 直接从 GitHub 安装（无需等 npm 发布）
dsh plugin --profile desktop add github:yicun0316/dsh-claude-slider
```

装完在 DSH 窗口按 **`Ctrl + R`** 生效。卸载：

```bash
dsh plugin --profile desktop remove dsh-claude-slider
```
