`dsh-claude-slider` 是面向 **DeepSeek Harness（DSH）** 的一体化界面美化与推理调节插件。它用顺滑的「直接拖」光学玻璃滑块取代原生下拉框，集成 **9 款自然/人文/材质/花卉/数字 Canvas 动效**、**莫奈动态取色与输入框流光框**、**输入框像素萌宠剧场**、**自定义角色立绘游标**与**多款趣味吸附音效**。

插件采用单文件零构建架构，**零外部依赖、零网络请求**，安装后按 `Ctrl + R` 即可生效。

## 核心亮点

### 顺滑直觉的推理滑块
- **直接拖 + 弹性落档**：拖动过程连续跟手，松手后自然吸附到最近档位，也支持直接点击档位节点直达。
- **随时一键还原**：在界面中可随时关闭滑块，无损切回 DSH 原生推理下拉框。

### 莫奈动态取色与输入框光学流光
- **莫奈三色引擎**：内置 **6 套精选莫奈色盘**（反重力星紫、莫奈睡莲、樱云薄雾、晨曦琥珀、碧水青瓷、深海鲸蓝），支持一键取色并自动派生主/辅/点缀三色，还可联动滑块配色。
- **随鼠流光框与环境晕色**：为输入框提供随鼠标移动的全周流光边框（支持「棱镜虹彩 / 莫奈色盘」双光谱切换）与周边柔光晕色，氛围强度实时可调。
- **光学液态玻璃外观**：支持浅色瓷白玻璃、深色曜石磨砂与跟随系统三模式，面板透明度（15%–100%）自由调节，附带 8 款经典主色与 Hex 拾色器。

### 60fps 输入框像素萌宠剧场
- 内置 **6 只风格各异的像素萌宠**（臭企鹅、反重力猫娘、鲸鱼娘女仆、小紫猫、暖橘小蟹、深海小鲸），支持**多只同屏陪伴**。
- **情境联动**：开始思考时起风晃动、推理完成后欢呼庆祝，日常支持自主散步、相遇互动打架，站位（左上 / 右上 / 分站）与缩放（0.8x–1.35x）随心配置。

### 角色立绘游标与智能裁边
- 内置精选角色形象（DeepSeek 鲸鱼娘、爱弥斯、多款 Q 版全身立绘与极简纯白），也支持**导入任意本地 PNG / JPG / SVG 图片**。
- **无损双档规格**：导入图片自动等比缩放并支持「导入自动裁边 / 一键裁边」去除多余白边或透明边，且可在**立绘档**（64px 脚踩轨道下沿）与**圆头档**（26px 圆形居中）之间无损切换，游标缩放支持 70%–140%。

### 趣味档位反馈音
- 内置 **5 款反馈音效**（机械微触、咕咕嘎嘎、杂鱼、哦鲸鲸、小黄鸭），同时支持上传本地 MP3 / WAV 自定义音效与独立音量控制。

## 快速安装

在终端运行对应命令安装插件：

```bash
# 桌面版（推荐，直接从 GitHub 获取最新 v2.20.0）
dsh plugin --profile desktop add github:yicun0316/dsh-claude-slider

# 网页版（GitHub 最新版）
dsh plugin --profile web add github:yicun0316/dsh-claude-slider

# 或通过 npm 安装稳定版
dsh plugin --profile desktop add dsh-claude-slider
```

安装完成后，在 DSH 客户端按 <kbd>Ctrl</kbd> + <kbd>R</kbd> 重新加载界面即可生效。

> [!TIP]
> 想先体验交互手感与动效？可直接用浏览器打开仓库中的 [`demo/index.html`](demo/index.html)，无需安装 DSH 即可离线预览全部 9 款动效、深浅主题与音效。

<details>
<summary>其他安装方式与卸载命令</summary>

**通过插件市场安装**

```bash
dsh plugin --profile desktop add dshmarket
```

安装 `dshmarket` 后，在界面插件市场中搜索 `dsh-claude-slider` 即可一键安装。

**本地开发源码软链接挂载**

克隆仓库后运行根目录 [`install.bat`](install.bat)（自动建立本地链接到 DSH 插件目录），随后在客户端按 `Ctrl + R` 即可热重载生效。

**卸载插件**

```bash
dsh plugin --profile desktop remove dsh-claude-slider
```

</details>

## 五栏极简面板与调校参数

点击滑块右上角设置入口即可展开液态玻璃抽屉，五大功能页签分工清晰：

| 页签 | 核心能力 |
| :--- | :--- |
| **动效** | 按「全部 / 自然 / 人文 / 材质 / 花卉 / 数字」筛选 9 款 Canvas 动效，实时调校**流速**与**亮度** |
| **外观** | 8 款预设主色 + Hex 拾色器、莫奈取色与 6 套三色预设、输入框光棱/晕色、面板透明度与深浅主题 |
| **萌宠** | 像素萌宠剧场开关、6 只萌宠多选、站位布局、自主散步 / 相遇打架开关与尺寸缩放 |
| **图标** | 内置角色立绘/头像切换、本地图片导入、自动裁边 / 一键裁边、立绘/圆头档位与游标大小 |
| **声音** | 5 款内置档位反馈音 + 本地 MP3/WAV 上传与实时音量调节 |

### 常用可调参数一览

| 参数 | 可调范围 | 默认值 |
| :--- | :---: | :---: |
| 动效流速 | `0.5x ~ 2.0x` | `1.0x` |
| 动效亮度 | `0.5x ~ 2.0x` | `1.0x` |
| 面板透明度 | `15% ~ 100%` | `90%` |
| 输入框氛围强度 | `10% ~ 100%` | `55%` |
| 萌宠缩放尺寸 | `0.80x ~ 1.35x` | `1.00x` |
| 游标图标大小 | `70% ~ 140%` | `100%` |
| 吸附反馈音量 | `0% ~ 100%` | `100%` |

## 隐私与性能护栏

> [!NOTE]
> - **零网络请求**：所有动效、图标与内置音效均内嵌于本地插件包，不连接外部服务器，不读写本地隐私文件，仅使用浏览器 `localStorage`（键名 `dsh-claude-slider.config.v2`）持久化界面偏好。
> - **后台自动休眠**：监听 `visibilitychange`，窗口隐藏或切到后台时立即停止 `requestAnimationFrame`；`Off` 档位下零逐帧绘制。
> - **无障碍支持**：全面遵守系统级 `prefers-reduced-motion` 设置，减少动态效果模式下自动保持静态高颜值画面。
